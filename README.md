# Bennie Smith — Cybersecurity Portfolio

A responsive static website for GitHub Pages. No installation, paid hosting, or build tools are required.

## Publish on GitHub Pages

1. Sign in to GitHub and create a public repository named `YOUR-USERNAME.github.io`, replacing `YOUR-USERNAME` with your actual GitHub username.
2. Extract this ZIP file on your computer.
3. In the repository, choose **Add file → Upload files**. Upload the contents of the extracted folder (not the ZIP or its parent folder). `index.html` must be at the root of the repository.
4. Commit the files to the `main` branch.
5. Open **Settings → Pages**. Select **Deploy from a branch**, choose **main** and **/(root)**, then save.
6. Visit `https://YOUR-USERNAME.github.io/`. Publishing can take up to 10 minutes.

Official instructions: https://docs.github.com/en/pages/quickstart

## Preview locally

Open `index.html` in your browser. All styles and interactions use local relative paths, so the website also works under a GitHub project repository path.

## Customize

- `index.html`: name, education, work experience, project summaries, and reference links.
- `styles.css`: colors, typography, layout, and mobile responsiveness.
- `script.js`: topic filters.
- `favicon.svg`: browser-tab initials.

## Content scope

The site uses the SNHU learning topics and work history discussed in ChatGPT. Academic exercises are explicitly described as learning rather than professional engagements. It does not claim certifications, production security results, or completed labs that have not been verified. Review the wording before publishing. No personal email, phone number, profile links, or lab screenshots were provided, so none are invented or included. Add approved contact/profile links when available.

To add evidence, include your own sanitized lab screenshots or write-ups and link them from the relevant project. Do not upload passwords, tokens, private school materials, or customer information.
