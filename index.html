Application securityLAB / 01

SQL injection and safe database queries

Studied how unsafe input can change the meaning of a SQL query and how parameterized queries keep values separate from SQL instructions.

Explore what I learned

Topics and tools

Input handling, escaping, parameterized queries, authentication bypass

Security takeaway

Use parameterized queries, validate input, and limit database permissions.

Application securityLAB / 02

Stored XSS and browser defenses

Explored how stored user input can execute scripts when a page renders it without safe output handling.

Explore what I learned

Topics and tools

Stored XSS, output encoding, Content Security Policy, HTTPS

Security takeaway

Encode output for its destination, sanitize permitted HTML, and apply CSP as an additional defense.
